# poco-ai/homebrew-agentero

Homebrew tap for [Agentero](https://github.com/poco-ai/Agentero).

## Formulae

- `agentero` — Headless Vault / Catalog CLI.

## Casks

- `agentero` — Agentero desktop app (macOS).

## Install

```bash
brew tap poco-ai/agentero
brew install agentero          # CLI
brew install --cask agentero   # Desktop app
```

## Maintenance

This tap is updated automatically by the main repository's release workflow.
Do not edit `Formula/agentero.rb` or `Casks/agentero.rb` by hand; the SHA-256
checksums are regenerated for every release.
